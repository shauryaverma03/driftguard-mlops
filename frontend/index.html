System Architecture & Pipeline Flow

Autonomous MLOps Lifecycle for Continuous Market Manipulation Detection

1

Feature Ingestion & Serving

FastAPI exposes /predict for scoring trades across 5 features. Incoming features and predictions are saved to the rolling SQLite window store.

2

Continuous KS-Drift Engine

Computes scipy.stats.ks_2samp per feature against the baseline distribution. Flags drift when p < 0.05 on ≥ 3 features.

3

Validation-Gated Retraining

Auto-triggers challenger retraining. Gated against baseline validation and drifted test benchmarks before registering and staging in MLflow.

4

Zero-Downtime Hot-Swap

Thread-safe model manager atomically swaps the active serving pointer in memory with zero downtime and emits Prometheus metrics on /metrics.
